# Sioni Prism Design System

## 목적

정보량과 조작 개수는 늘리지 않고, 빛·재질·색의 깊이로 8살 어린이가 기대감을 느끼는 화려한 영어 모험 세계를 만든다.

## 핵심 원칙

1. 한 화면의 주 행동은 하나만 강하게 빛낸다.
2. 화려함은 장식의 개수가 아니라 색의 층과 재질로 만든다.
3. 시오니의 청록빛과 미션의 산호·금빛을 역할별로 구분한다.
4. 모든 광원 효과 뒤에서도 본문 대비와 터치 영역을 유지한다.
5. `prefers-reduced-motion`에서는 반복 모션을 제거한다.

## 색상 토큰

| 토큰 | 값 | 역할 |
|---|---|---|
| Prism Coral | `#ff6f61` | 주 행동, 용기, 말하기 |
| Prism Gold | `#ffc94a` | 보상, 진행, 성취 |
| Prism Aqua | `#48ddc5` | 시오니 에너지, 듣기 |
| Prism Cyan | `#45bde9` | 하늘, 탐험, 정보 |
| Prism Ink | `#203653` | 제목과 주요 문장 |
| Pearl Glass | `rgba(255,255,255,.82)` | 카드 재질 |

## 재질

- `Pearl`: 따뜻한 흰색 그라데이션과 얇은 흰색 테두리
- `Energy`: 청록빛 방사형 광원과 작은 외곽 링
- `Reward`: 금빛과 산호색의 짧은 그라데이션
- `Sky Glass`: 배경을 가볍게 비추는 반투명 표면

## 그림자 단계

- 낮음: 작은 통계 칩과 보조 버튼
- 중간: 접힌 놀이 메뉴와 메시지
- 높음: 오늘의 무대, 미션 카드, 주요 화면 헤더
- 광원: CTA·시오니 코어처럼 의미가 있는 요소에만 적용

## 모션

- 환경 오로라: 12초
- 시오니 호흡: 5.5초
- 코어 점멸: 2초
- 주 행동 그라데이션: 7초
- 직접 조작 피드백: 0.2~0.7초

반복 환경 모션은 느리게, 아이가 누른 결과는 즉시 보여준다.

## 컴포넌트 규칙

- 주 CTA는 화면당 하나만 산호·금빛으로 표시한다.
- 일반 카드는 진주 재질을 사용하고 강한 색상 면을 사용하지 않는다.
- 학습 성공은 금빛, 듣기는 청록, 말하기는 산호색으로 일관되게 표시한다.
- 펼쳐지는 보조 기능은 닫힌 상태에서 시각적으로 경쟁하지 않는다.
