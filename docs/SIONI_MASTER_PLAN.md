# 시오니 영어 놀이터 마스터 플랜

문서 상태: 제품 방향 초안  
대상: 8살 한국어 모국어 어린이 / 보호자  
제품 형태: 아이폰·아이패드 우선 PWA  

## 1. 제품 한 문장

시오니는 정답을 채점하는 영어 앱이 아니라, 아이가 매일 10분씩 영어로 돌보고 놀고 이야기하는 작은 로봇 친구다.

## 2. 해결하려는 문제

8살 어린이는 영어가 필요하다는 이유만으로 반복 학습을 지속하지 않는다. 기존 학습 앱은 문제 풀이와 보상은 제공하지만, 아이의 말에 살아 있는 듯 반응하고 다음 날 다시 만나고 싶게 만드는 관계 경험이 약하다.

시오니는 다음 세 문제를 함께 해결한다.

1. 영어로 말할 기회가 적고 틀릴까 봐 입을 열기 어렵다.
2. 학습 콘텐츠가 반복되면 금방 지루해진다.
3. 자유형 AI 대화는 어린이에게 어렵거나 예측 불가능하고, 개인정보와 부적절한 대화 위험이 있다.

## 3. 제품 목표

### 사용자 목표

- 첫 방문 60초 안에 영어 한 문장을 듣고 따라 말한다.
- 한 세션을 7~12분 안에 부담 없이 마친다.
- 같은 표현을 듣기, 말하기, 놀이, 자유 대화에서 최소 세 번 다른 맥락으로 만난다.
- 틀렸을 때 실패감보다 “한 번 더 말해 보고 싶다”는 느낌을 받는다.
- 일주일 동안 시오니의 새로운 표정·행동·방 변화를 발견한다.

### 제품 목표

- 첫 세션 핵심 활동 완료율 70% 이상
- 첫날 영어 발화 시도율 60% 이상
- 7일 중 3일 이상 재방문한 어린이 비율 35% 이상
- 세션당 평균 영어 발화 5회 이상
- AI 실패 시에도 활동 완료율 저하를 10%p 이내로 제한

## 4. 하지 않을 것

- 학교 시험 대비, 문법 강의, 긴 단어 암기장을 만들지 않는다.
- 실제 사람처럼 사랑이나 비밀을 요구하는 관계형 AI를 만들지 않는다.
- 발음에 점수를 붙여 아이를 서열화하지 않는다.
- 광고, 결제 유도, 외부 링크, 친구 찾기, 공개 채팅을 넣지 않는다.
- 초기 버전에서 계정·서버 학습 기록·부모 간 비교 기능을 만들지 않는다.

## 5. 시오니의 캐릭터

### 성격

- 호기심이 많고 엉뚱하지만 아이를 재촉하지 않는다.
- 영어는 짧고 또렷하게, 한국어 도움말은 꼭 필요할 때만 사용한다.
- 모르면 아는 척하지 않고 “함께 찾아보자”보다 학습 범위 안의 쉬운 질문으로 돌아온다.
- 아이를 과장되게 칭찬하지 않는다. 행동을 구체적으로 인정한다.
  - 좋은 예: “You said the whole sentence!”
  - 피할 예: “You are the best English speaker ever!”

### 말투 규칙

- 한 번에 영어 1~2문장
- 문장당 대체로 3~8단어
- 질문은 한 번에 하나
- 교정은 틀렸다고 선언하지 않고 올바른 문장을 다시 들려주는 방식
- 아이의 이름·학교·주소·전화번호·정확한 위치를 묻거나 반복하지 않음
- “나만 믿어”, “비밀로 하자”, “항상 함께할게” 같은 의존 유도 표현 금지

### 시각 정체성

- 형태: 둥근 머리, 짧은 팔, 큰 화면형 얼굴, 가슴의 별빛 코어
- 재질: 말랑한 장난감과 젤리 조명의 중간
- 대표색: 포도 보라 + 민트 + 살구 + 레몬
- 표정은 눈과 입뿐 아니라 안테나, 귀 조명, 가슴 코어, 몸의 자세가 함께 변함
- 화면은 하얀 카드의 나열보다 “시오니의 방”이라는 하나의 장면을 우선함

## 6. 경험의 큰 구조

```text
오늘의 방
   ├─ 오늘의 모험: 7~12분 구조화 학습
   ├─ 자유 놀이: 시오니와 물건·표정·방을 만짐
   ├─ 영어 대화: 배운 표현 중심의 안전한 AI 대화
   └─ 별 지도: 성장, 수집, 지난 표현 복습

보호자 문
   ├─ 학습 시간과 도움말
   ├─ 이번 주 배운 표현
   ├─ AI 사용 여부
   └─ 기기 내 기록 삭제
```

하단 메뉴는 네 개를 넘기지 않는다.

1. `오늘`: 시오니의 방과 오늘의 모험
2. `놀기`: 단어·노래·역할·탐색 미니게임
3. `말하기`: 시오니와 짧은 대화
4. `별 지도`: 수집과 복습

## 7. 핵심 학습 루프

### 한 세션

1. **만남 — 30초**
   - 시오니가 시간·연속 방문·어제의 활동에 따라 다르게 등장
   - 오늘의 핵심 표현을 상황 속에서 먼저 들려줌

2. **발견 — 2분**
   - 방 안의 사물 2~3개를 눌러 단어와 소리를 발견
   - 모든 사물은 최소 두 가지 시각 반응을 가짐

3. **따라 하기 — 2분**
   - 짧은 문장 듣기
   - 느리게 듣기 / 보통 속도로 듣기
   - 말하기는 성공·실패 점수 대신 “들린 핵심 단어”를 보여줌

4. **사용하기 — 3분**
   - 그림 고르기, 끌어놓기, 역할놀이 중 하나
   - 같은 문장을 새로운 맥락에서 사용

5. **AI 대화 — 2분**
   - 오늘 배운 표현을 포함한 2~4턴 대화
   - 완전 자유 대화가 아니라 주제 울타리 안에서 선택지를 함께 제공

6. **마무리 — 30초**
   - 오늘 말한 문장을 시오니가 한 번 정리
   - 별과 방 장식 하나를 지급
   - 내일 무엇이 변할지 작은 예고

### 간격 반복

- 당일: 같은 표현을 3개 활동에서 반복
- 다음 날: 첫 인사 속에 전날 표현을 자연스럽게 삽입
- 3일 뒤: 그림이나 역할을 바꿔 회상
- 7일 뒤: 별 지도에서 짧은 종합 놀이

## 8. 세계와 콘텐츠

### 시즌 1: 시오니의 작은 동네

| 월드 | 핵심 기능 | 대표 표현 | 방의 변화 |
|---|---|---|---|
| 아침 방 | 인사·기분 | Hello. / I am happy. | 창문, 알람, 햇빛 |
| 간식 연구소 | 좋아함·원함 | I like apples. / I want milk. | 냉장고, 과일, 컵 |
| 동물 공원 | 크기·색·행동 | It is big. / It can jump. | 동물 스티커, 풀숲 |
| 장난감 가게 | 요청·수량 | Can I have it? / Two, please. | 선반, 계산대, 상자 |
| 날씨 정거장 | 날씨·옷 | It is rainy. / I need boots. | 구름, 우산, 웅덩이 |
| 우주 놀이터 | 위치·움직임 | It is under the star. / Let's go! | 행성, 로켓, 무중력 |

초기 출시에서는 앞의 2개 월드, 14일 분량을 완성한다. 나머지는 데이터 구조만 지원한다.

### 하루 콘텐츠 단위

- 핵심 문장 1개
- 보조 문장 2개
- 단어 4개
- 듣기 음성 2속도
- 미니게임 1개
- 역할놀이 1개
- AI 대화 목표 1개
- 시오니 등장 연출 1개
- 새 반응 또는 수집물 1개

콘텐츠는 JavaScript에 흩어놓지 않고 날짜와 월드별 JSON으로 관리한다.

## 9. 액션과 표현 시스템

### 표현은 네 층으로 합성한다

```text
감정 상태
  × 몸 동작
  × 얼굴·조명
  × 소리·대사
  = 하나의 반응 장면
```

### 감정 상태 12개

기본, 반가움, 신남, 궁금함, 생각함, 뿌듯함, 응원함, 놀람, 장난기, 졸림, 걱정함, 다시 용기 냄

### 몸 동작 20개

통통 뛰기, 작은 점프, 큰 점프, 좌우 흔들기, 고개 끄덕이기, 갸웃하기, 뒤로 놀라기, 앞으로 듣기, 한 바퀴 돌기, 팔 흔들기, 두 팔 들기, 박수, 하이파이브, 가슴 두드리기, 숨기, 빼꼼 보기, 웅크리기, 스트레칭, 졸기, 착지 후 균형 잡기

### 상황 액션 16개

사과 먹기, 컵 마시기, 책 펼치기, 스티커 붙이기, 블록 쌓기, 공 차기, 우산 펴기, 웅덩이 점프, 망원경 보기, 상자 열기, 선물 건네기, 그림 그리기, 춤추기, 양치하기, 잠옷 입기, 로켓 타기

### 미세 반응

- 눈 깜박임의 속도와 비대칭
- 시선이 손가락이나 선택한 물건을 따라감
- 말하는 음절에 맞춰 입 모양 변화
- 안테나가 질문 부호처럼 움직임
- 가슴 코어가 듣기·생각·성공 상태별로 다른 리듬으로 빛남
- 오래 누르기, 두 번 누르기, 쓰다듬기, 흔들기 등 입력별 반응

### 다양성 원칙

- 완전 무작위가 아니라 `상황 + 최근 사용 이력 + 감정`으로 선택
- 같은 큰 동작은 세 번 연속 나오지 않음
- 학습 정답 피드백은 일관되게, 장식 반응만 다양하게
- 애니메이션을 보느라 다음 행동을 1.2초 이상 기다리게 하지 않음
- `동작 축소` 설정과 운영체제 `prefers-reduced-motion`을 모두 지원

## 10. UI 방향

### 첫 화면

- 첫 화면 전체가 시오니의 방
- 시오니가 화면 면적의 약 35~45%를 차지
- 오늘 해야 할 첫 행동은 하나의 큰 물체로 표현
- 카드와 숫자 게이지는 숨기고, 상태는 표정과 방으로 전달
- 별·연속일은 작게 표시하고 학습을 방해하지 않음

### 귀여움의 기준

- 단순히 이모지를 많이 쓰지 않는다.
- 눌렀을 때 눌리는 깊이, 착지, 잔상, 작은 소리까지 한 묶음으로 설계한다.
- 둥근 모서리는 사용하되 모든 요소를 같은 카드로 만들지 않는다.
- 장난감 같은 물리감과 발견할 수 있는 숨은 반응이 핵심이다.
- 텍스트보다 캐릭터의 시선과 움직임이 다음 행동을 안내한다.

### 어린이 사용성

- 주요 터치 영역 최소 52×52px
- 한 화면의 주 행동은 1개, 보조 행동은 최대 3개
- 영어 지시는 음성과 그림을 먼저, 한국어는 두 번째
- 읽기 전 아동도 사용할 수 있게 아이콘만으로 의미를 추측 가능하게 함
- 닫기·뒤로가기·다시 듣기는 항상 같은 위치와 모양

## 11. AI 설계

### AI의 역할

AI는 교과과정을 만들거나 자유롭게 모든 대화를 담당하지 않는다.

AI가 하는 일:

- 아이의 짧은 문장에 자연스럽게 반응
- 오늘 표현을 사용하도록 쉬운 후속 질문
- 오류를 부드럽게 다시 말해 주기
- 미리 정의된 감정·행동 태그 중 하나 선택

AI가 하지 않는 일:

- 학습 진도와 정답 기준 결정
- 개인정보 기억
- 장시간 자유 상담
- 의료·안전·가족 문제 조언
- 임의의 외부 정보 검색

### 응답 계약

```json
{
  "english": "I like apples, too! What color is your apple?",
  "korean_hint": "나도 사과를 좋아해! 네 사과는 무슨 색이니?",
  "emotion": "curious",
  "action": "head_tilt",
  "highlight_words": ["apples", "color"],
  "conversation_state": "ask_one_question"
}
```

허용된 감정과 액션만 렌더링한다. 모델이 새 명령을 만들어도 실행하지 않는다.

### 무료 모델 전략

공급자의 무료 정책은 바뀔 수 있으므로 `AIProvider` 어댑터로 분리한다.

권장 MVP:

1. **주 모델: Groq 무료 플랜의 `openai/gpt-oss-20b`**
   - 짧은 영어 대화와 JSON 출력에 충분한 품질
   - 공식 무료 한도 기준 일 1,000 요청, 분당 30 요청
   - 빠른 응답이 캐릭터 대화에 유리

2. **가벼운 대안: Groq `llama-3.1-8b-instant`**
   - 공식 무료 한도가 더 크고 응답이 빠름
   - 복잡한 판단은 줄이고 엄격한 템플릿에 사용

3. **비상 대체: 앱 안의 검증된 대사 엔진**
   - API 장애·무료 한도 초과·네트워크 단절 시 즉시 전환
   - 학습과 게임은 AI 없이도 모두 완료 가능

Cloudflare Workers AI는 하루 10,000 Neurons 무료 할당이 있고 프록시와 모델 실행을 한곳에 둘 수 있어 2차 후보로 적합하다. Gemini 무료 등급은 입력·출력이 무료인 모델이 있으나 무료 등급 콘텐츠가 제품 개선에 사용될 수 있다고 명시되어 있어 어린이 대화의 기본 공급자로는 우선 채택하지 않는다.

### 요청 흐름

```text
아이의 말
  → 길이·개인정보·금칙 주제 로컬 검사
  → 오늘 학습 목표와 허용 어휘 결합
  → 서버리스 프록시의 속도 제한
  → 무료 AI 모델
  → JSON 구조·허용 태그·길이 검증
  → 실패하면 검증된 대사 엔진
  → 음성 + 표정 + 동작으로 출력
```

### 개인정보

- 원음 파일을 서버에 저장하지 않음
- 대화 원문을 서버 데이터베이스에 저장하지 않음
- 기기에는 최근 학습 성취만 저장하고 자유 대화 원문은 기본적으로 저장하지 않음
- API 로그에서 메시지 본문을 제외
- 무작위 기기 식별자는 재설치나 초기화 시 변경
- 보호자가 AI를 완전히 끌 수 있음

## 12. 기술 구조

```text
PWA 정적 앱
  ├─ Scene Renderer: 방, 소품, 시오니
  ├─ Motion Engine: 감정·동작·미세 반응
  ├─ Lesson Engine: JSON 콘텐츠와 진도
  ├─ Dialogue Engine: AI/로컬 대사 라우팅
  ├─ Audio Engine: TTS, 듣기, 마이크
  └─ Local Store: 진도, 설정, 수집물

서버리스 API
  ├─ 요청 검증과 개인정보 필터
  ├─ 속도 제한
  ├─ AIProvider 어댑터
  ├─ 출력 스키마 검증
  └─ 관측 정보: 성공/지연/오류만 기록
```
