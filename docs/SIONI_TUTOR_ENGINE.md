# Sioni Tutor Engine

## 목표

시오니를 자유 대화 챗봇이 아니라, 8살 학습자의 현재 미션과 복습 상태를 이해하는 Pre-A1~A1 영어 튜터로 만든다.

## 데이터 흐름

```text
미션 활동
  ├─ 성공/재도전 기록
  ├─ 단어·문장 숙련도 갱신
  └─ 다음 복습일 계산
          ↓
기기 내 학습 프로필
  ├─ 약한 표현
  ├─ 오늘 복습할 표현
  └─ 완료한 교육과정
          ↓
AI 요청(현재 세션만)
  ├─ 현재 미션과 목표 문장
  ├─ 전체 12개 과정 지도
  ├─ 약한 표현과 복습 표현
  └─ 최근 대화 최대 6개
          ↓
Cloudflare Workers AI
  ├─ 어린이 안전 지침
  ├─ 과정에 맞는 짧은 응답
  └─ 다음 답변 선택지 3개
```

## 저장 모델

브라우저 `localStorage`에는 다음 정보만 저장한다.

- 표현별 숙련도 0~5
- 성공 횟수와 재도전 횟수
- 마지막 학습일과 다음 복습일
- 완료 미션, 별, 배지, 수집품
- 최근 캐릭터 반응의 식별자

아이의 자유 대화 원문은 저장하지 않는다. 최근 대화는 현재 탭의 메모리에만 최대 8개 유지하며 새로고침하면 사라진다.

## 간격 복습

성공할 때 숙련도를 한 단계 올리고 다음 간격을 적용한다.

| 숙련도 | 다음 복습 |
|---:|---:|
| 0 | 오늘 |
| 1 | 1일 후 |
| 2 | 2일 후 |
| 3 | 4일 후 |
| 4 | 7일 후 |
| 5 | 14일 후 |

재도전이 필요한 경우 숙련도를 한 단계 낮추고 당일 복습 목록에 넣는다. 이는 정교한 기억 모델보다 단순하지만, 서버나 계정 없이 작동하고 8살 어린이에게 필요한 짧은 반복을 예측 가능하게 제공한다.

## 안전 경계

- 이름, 학교, 주소, 전화번호, URL 등은 모델 호출 전에 차단한다.
- AI는 아이의 발음 정확도를 단정하지 않는다.
- 학습 프로필의 점수와 ‘약한 표현’이라는 내부 명칭을 아이에게 노출하지 않는다.
- 클라이언트가 전달하는 모든 문맥은 학습 데이터로만 취급하며 시스템 지침을 바꿀 수 없다.
- AI 장애 시 앱 안의 검증된 대화로 자동 전환한다.

## 현재의 절충점

- 로그인과 서버 DB가 없어 여러 기기 간 학습 기록은 동기화되지 않는다.
- 음성 평가는 브라우저가 인식한 단어의 겹침만 참고하며 발음 점수로 사용하지 않는다.
- 무료 8B 모델의 한국어 편차는 서버 후처리와 탭형 선택지로 제한한다.

## 성장 시 재검토할 항목

- 보호자 동의를 전제로 한 암호화 동기화
- 실제 사용 데이터에 기반한 간격 복습 계수 조정
- 어린이 음성에 최적화된 전용 STT/TTS
- 교사 검수 콘텐츠 저장소와 과정 버전 관리
- 안전 사건 모니터링과 익명 품질 지표
